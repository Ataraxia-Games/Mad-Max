# Mad Max - Колодостроительная Игра - Дизайн Документ

[Дизайн пользовательского интерфейса](ui_design_doc.md)

## 1. Обзор Игры
- Жанр: Стратегическая колодостроительная игра
- Сеттинг: Вселенная Mad Max
- Количество игроков: 3
- Роли игроков: Главари банд рейдеров
- Игровое поле: Сетка 7x7
- Игровые фишки: Отряды рейдеров
- Условие победы: Сбор победных очков через приобретение карт

## 2. Структура Игрового Поля
### 2.1 Расположение Клеток
- Всего клеток: 49 (7x7)
- Перекрестки: 16 клеток (1, 3, 5, 7, 15, 17, 19, 21, 29, 31, 33, 35, 43, 45, 47, 49)
- Слоты для карт: 9 клеток (9, 11, 13, 23, 25, 27, 37, 39, 41)
- Остальные 24 клетки (Обстоятельства): клетки, среди случайных появляются 

### 2.2 Типы Клеток
1. Перекрестки
   - Точки перемещения
   - Игроки могут перемещаться только между соседними перекрестками
   - Перемещение ограничено вертикальными/горизонтальными путями

2. Слоты для Карт
   - Места для получения новых карт
   - Источники победных очков

## 3. Механики Игроков
### 3.1 Начальная Настройка
- Каждый игрок начинает с симметричной колоды из 10 карт:
  - 3 карты перемещения
  - 3 карты атаки
  - 3 карты дипломатии
  - 1 карта отдыха

### 3.2 Структура Хода
1. Случайное определение порядка хода
2. Игрок берет карты из своей колоды
3. Игрок выполняет действия, используя карты
4. Конец хода

### 3.3 Система Перемещения
- Игроки должны использовать карты перемещения для движения
- Перемещение ограничено соседними перекрестками
- Допускается только вертикальное/горизонтальное перемещение
- Карты перемещения расходуются после использования

## 4. Система Карт
### 4.1 Типы Карт
1. Стартовые Карты
   - Перемещение
   - Атака
   - Дипломатия/Взаимодействие
   - Отдых

2. Карты Игровой Колоды
   - События
   - Снаряжение
   - Персонажи
   - (Другие типы будут определены позже)

### 4.2 Приобретение Карт
- Игроки соревнуются за карты в слотах
- Несколько игроков могут пытаться получить одну и ту же карту
- Полученные карты добавляются в колоду игрока

## 5. Взаимодействие Игроков
### 5.1 Текущие Механики
- Конкуренция за карты
- Возможность кражи карт
- Блокировка позиций

### 5.2 Будущие Рассмотрения
- Система прямого конфликта
- Механика боя
- Конкуренция за ресурсы

## 6. Победные Очки
- Привязаны к картам игровой колоды
- Точные значения будут определены в процессе тестирования
- Несколько способов получения очков через приобретение карт
