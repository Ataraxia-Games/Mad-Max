# Mad Max - Описание Карт

## 1. Стартовые Карты

| Тип Карты | Название | Описание | Количество | Эффект |
|-----------|----------|-----------|-----------|---------|
| Перемещение | Погнали! | Базовая карта перемещения | 1 | Перемещение на соседний перекресток |
| Атака | Огонь! | Базовая карта атаки | 1 | Нанесение 1 урона карте/1 ранения оппоненту |
| Дипломатия | Переговоры | Базовая карта дипломатии | 1 | Улучшение отношения с картой на поле |
| Отдых | Восстановление | Базовая карта отдыха | 1 | Уберите ранение |

## 2. Карты Игровой Колоды

### 2.1 События

| Название | Эффект |
|----------|---------|
| Песчаная Буря | Блокировка перемещения всех игроков |
| Набег Мародеров | Кража случайной карты у каждого игрока |
| Торговый Караван | Дополнительная карта в руку |
| Восстание | Смена позиций всех игроков |

### 2.2 Снаряжение

| Название | Эффект | Победные Очки |
|----------|---------|---------------|
| Броня | Защита от одной атаки | 1 |
| Оружие | +1 к силе атаки | 1 |
| Топливо | Дополнительное перемещение | 1 |
| Редкий Модуль | Специальная способность | 2 |

### 2.3 Персонажи

| Название | Эффект | Победные Очки |
|----------|---------|---------------|
| Механик | Ремонт снаряжения | 1 |
| Разведчик | Просмотр верхней карты колоды | 1 |
| Вожак | Усиление одного союзника на 1 ход, только если рядом | 2 |
| Легендарный Воин | Атака с силой 3, но только если у вас нет других карт на руке | 3 |

### 2.4 Ранения

| Название | Эффект | Способ Избавления |
|----------|---------|-------------------|
| Ушиб | -1 к силе атаки | Отдых в безопасной зоне |
| Порез | -1 к перемещению | Использование аптечки |
| Ожог | Пропуск хода | Лечение у механика |
| Перелом | -2 к всем действиям | Длительный отдых |
| Отравление | Потеря карты каждый ход | Антидот |
| Кровотечение | Потеря 1 HP каждый ход | Перевязка |
| Критическое Ранение | Ограничение действий | Срочная медицинская помощь |
| Смертельное Ранение | Смерть персонажа | Невозможно |

## 3. Карты точек интереса
| Название | Эффект |
|----------|---------|
| 1. Нитро | Проехав через, можете сделать дополнительное перемещение |
| 2. Свалка | Проехав через, удалите карту из своей колоды |
| 3. Торговец | Обменяйте карту из руки на карту из игровой колоды |
| 4. Смертельная Гонка | Поучаствуйте в соревновании за победные очки |
| 5. Док | Сбросьте карту, чтобы удалить ранение |
| 6. Завал | Соседние с ним перекрёстки не соединены и через него нельзя перемещаться |
| 7. Полигон | Получите карту атаки из игровой колоды |
| 8. Лаборатория | Улучшите одну карту из руки |
| 9. Бункер | Получите карту брони или сбросьте ранение |
| 10. Радиоактивная Зона | Получите карту мутации, дающую новую способность и ранение |
| 11. Оазис | Восстановите все карты из сброса в колоду |
