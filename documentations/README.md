# Mad Max - Колодостроительная Игра

Прототип стратегической колодостроительной настольной игры во вселенной Mad Max.

![Скриншот игры](https://i.imgur.com/hXcF0kJ.jpg)

## Описание

Mad Max - это стратегическая колодостроительная игра, в которой игроки принимают роли главарей банд рейдеров в постапокалиптическом мире. Игроки перемещаются по игровому полю, собирают ресурсы, улучшают свои колоды карт и соревнуются за победные очки.

## Особенности прототипа

- Игровое поле 7x7 с перекрестками, слотами для карт и точками интереса
- 3 игрока с уникальными стартовыми колодами
- Механика перемещения между перекрестками
- Взаимодействие с точками интереса, дающими различные эффекты
- Система карт (перемещение, атака, дипломатия, отдых)
- Победа через набор победных очков

## Технические детали

Прототип разработан на JavaScript с использованием принципов SOLID:

- **Single Responsibility Principle**: Каждый класс отвечает за одну задачу
- **Open/Closed Principle**: Классы открыты для расширения, закрыты для модификации
- **Liskov Substitution Principle**: Подклассы могут использоваться вместо базовых
- **Interface Segregation Principle**: Разделение интерфейсов на специфические части
- **Dependency Inversion Principle**: Высокоуровневые модули не зависят от низкоуровневых

## Запуск прототипа

1. Клонируйте репозиторий:
```
git clone https://github.com/yourusername/mad-max-game.git
```

2. Запустите локальный сервер (например, с помощью Python):
```
cd mad-max-game
python -m http.server 8000
```

3. Откройте в браузере:
```
http://localhost:8000/src/
```

## Игровой процесс

1. Игроки ходят по очереди
2. На каждом ходу игрок может сыграть одну карту:
   - Карта перемещения: переместиться на соседний перекресток
   - Карта атаки: атаковать другого игрока
   - Карта дипломатии: взаимодействовать с другим игроком
   - Карта отдыха: восстановиться от ранений
3. Игроки могут активировать точки интереса, находясь на них
4. Цель игры - набрать 15 победных очков
