# Mad Max - Дизайн Пользовательского Интерфейса. Адаптировано под мобильные девайсы.

## 1. Основной Экран Игры (Сверху вниз)

### 1.1 Информационная Панель (Хедер)
- Отображение статуса всех игроков в строчку
    - Текущее количество победных очков
    - Количество карт на руках
    - Игрок выделен, если сейчас его ход

### 1.2 Игровое Поле
- Центральный элемент интерфейса - сетка 7x7
- Перекрестки отмечены специальными маркерами
- Слоты для карт визуально выделены
- Текущая позиция игрока отмечена уникальным маркером
- Возможные ходы подсвечиваются при наведении

### 1.3 Панель Карт (Нижняя панель)
Слева-направо:
    - Колода игрока с иконкой количества карт
    - Отображение текущей руки игрока
    - Колода сброса лицом вверх
Элементы Управления. Строка над панелью карт. Несколько кнопок в строчку
    - Кнопка "Завершить ход"
    - Кнопка "Отменить действие"

## 2. Адаптивность
- Поддержка разных разрешений экрана
- Масштабируемый интерфейс
- Оптимизация для мобильных устройств
- Настройки отображения
